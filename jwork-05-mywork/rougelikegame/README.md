### 最终游戏玩法确定(brain storm)

1. 怪物分批次出现，在某系点位刷新不同类型的怪物，并且只有场上没有上次的怪物的时候下一波怪物才会刷新
2. rouge like元素：
   + 每当战胜一波怪物，刷新出宝箱，宝箱中含有随机的buff
   + （待定）：更换武器（要求bullet和武器强绑定而和玩家解绑）
3. 玩家移动方式：通过WASD在**平面**上移动
4. 玩家攻击方式：通过鼠标点击射击
5. 近战怪物追踪玩家方式：在一定范围内，怪物直线朝玩家移动（要求：怪物速度必须低于玩家）
   （当有范围内有多个玩家时，目标为最近的哪个；当追踪玩家时有新的玩家进入范围，不改变目标）
6. 远程怪物攻击方式：检索地图上距离最近的玩家，每个射击周期都向该玩家的位置发射bullet
7. 远程怪物移动方式：随机移动
8. 宝箱：通过emoji的图标表示，碰撞之后消失（要求：仅仅和玩家碰撞之后才会消失）
9. boss设计
   + 出现时间：在5的整数次波数过去之后出现，
   + 具有较大体积，
   + 全屏攻击方式（从屏幕的一端生成bullet，向另一端移动）
   + 屏幕上方显示血条（不知道怎么做）
10. 受击：
    + 玩家：去除碰撞组件一段时间（无敌阶段），同时提高透明度（渲染表现），随后碰撞组件和透明度恢复
